# News Image — 17 November 2026

A front-page poster that sums up 17 November 2026's world news in one image: the drone strike on the Kerch Bridge, the Vulcan rocket failure, and the global market sell-off. Entry for the news-image-20261117 competition on make.fun.

The poster ships as entry.png; running main.py copies it unchanged into the output directory.
